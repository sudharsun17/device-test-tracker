# Device Test Tracker

A manual QA practice project for consumer devices, built in 2026 as a personal project with AI assistance.

## What is in this repository

| File | Purpose |
| --- | --- |
| `index.html` | Web app to write, run and track test cases (Pass / Fail / Blocked) with a live pass-rate summary |
| `Smartphone_Manual_Test_Project.xlsx` | 25 smartphone test cases, defect log and execution summary |
| `Test_Case_Answer_Templates.xlsx` | Wording templates for recording pass and fail results |

## How to use

1. Open `index.html` in a browser, or open the live page if GitHub Pages is enabled.
2. Execute the test cases in the spreadsheet on a real device.
3. Record the actual result and mark each case Pass, Fail or Blocked.
4. Log every failure in the Defect Log with steps to reproduce, expected result, actual result and severity.

## Skills practised

Manual test execution, test case writing, defect reporting, severity assessment, Excel-based tracking, HTML, CSS and JavaScript.
